# Information Storage and Retrieval – LP3

This repository contains the **Laboratory Practice III (LP3)** implementations for the **Information Storage and Retrieval (ISR)** subject.

The practicals cover topics such as conflation, clustering, inverted files, information retrieval evaluation measures, feature extraction, web crawling, and weather data retrieval.

## 📚 Assignments

| No. | Assignment | Technology |
|-----|------------|------------|
| 1 | Conflation Algorithm | Java |
| 2 | Single-Pass Clustering | Java |
| 3 | Inverted Files | Java |
| 4 | Precision and Recall Calculator | Java |
| 5 | F-Measure and E-Measure | Java |
| 6 | 2D Feature Extraction | Python / Jupyter Notebook |
| 7 | E-Commerce Web Crawler | Python / Jupyter Notebook |
| 8 | Weather Report using API | Python / Jupyter Notebook |
